## 1. 重点条目

### 1.1 表格铺满宽度(已修,本次核对确认)

Rust `src/text/node.rs:1688-1796`:外层 `w_full` + 估算 max_w,列按 `Table::normalized_column_ratios`(node.rs:536-556)比例分,短表格也拉满。Go 旧版 grid shrink-to-fit(view.go:1827-1831 旧行号)只占内容宽。

**已修**:工作树 `view.go:1322` 回调签名携带 `runStyle` 并逐层下传(Strong/Emphasis/Strikethrough 分支 view.go:1347-1357),`spans` 用回调带来的样式构造 `base`(view.go:1258),`Strikethrough` case 补齐(view.go:1352)。测试随本次提交验证。

## 3. 功能 diff

**快捷键**(Rust `workspace/mod.rs:128-186` vs Go `menu.go:60-160` + `shell.go:662-681`):ctrl-o/f/w/f4/tab/shift+tab/a/home/end/f5/b/shift+e/=/-/0、escape 关搜索,**全部对齐**。上一轮列的"ctrl-shift-= 备用弦缺失"已过时:工作树 `shell.go:677-680` RegisterShortcuts 已挂 `Ctrl|Shift+Equal` 为 ZoomIn 副键。Go 多出 F3/Shift+F3(Ctrl+F/F3 是 Go 有意的浏览器惯例)、Ctrl+R 刷新副键、Ctrl+, 直达设置。搜索框内 Enter/Shift+Enter 导航两边都有(searchbar.go OnTextKey vs search_bar.rs on_key_down)。

**CLI / 关联 / 单实例**:Rust main.rs:26 `--register` + 位置参数 + ipc.rs named pipe 单实例转发 + bring_window_to_foreground(mod.rs:2565 起 AttachThreadInput 方案)。Go 对齐:`register_windows.go`(md/markdown)、`main.go:168` RequestSingleInstanceLock、`main.go:171-177` OnSecondInstance → 过滤 md 打开 + activate(`main.go:118-127` Restore+Focus,窗口未建时 activatePending 挂起)、OnOpenFile(main.go:167)承接关联启动。上一轮"单实例待验证"已核销。

**窗口状态**:Rust config.rs 存 x/y/w/h/is_maximized,启动恢复(mod.rs:145-172);Go 由 mygo 承担:`main.go:206` `StateKey: "main"`。上一轮待核项核销,语义等价。

**设置项**(config.rs:62-138 vs internal/settings/settings.go:52-73):逐字段对应(含 explorer_sort_mode:67);差异仍是 Rust 存窗口坐标(mygo StateKey 等价)与 sidebar_tab(Go 无侧栏 tab,有意偏离)。Go 多 accent_theme/layout/language。

**标签管理**:tab 右键 7 项(Rust mod.rs:2280-2450)Go tabs.go:135-159 全对齐;hover tooltip 完整路径(Rust mod.rs show_tab_tooltip)对齐(tabs.go:178);超宽横向滚动 + 激活 tab 自动滚入(Rust request_scroll_to_tab)对齐(tabs.go strip + ScrollIntoView + wheel);无拖拽排序、无未保存标记,两版一致。残留:tab 宽度上限(§1.3 P2)。

**搜索**:正则/大小写 toggle、Enter/Shift+Enter、上下项按钮、关闭、计数、10000 上限(Rust MAX_MATCHES search_bar.rs:16)全对齐(searchbar.go + doc/search.go:20)。Go 增强:打开时用选区预填 query;无命中/坏模式有专属文案。

**文件监视/auto refresh**:对齐(watch.go + AutoRefresh 设置);残留:树目录级刷新(§1.3 P1)。

**缩放**:ctrl+=/-/0 两边有;语义差异见 §4。打印/PDF 两版都无。

**系统拖放**:Rust on_drop ExternalPaths 直接 open_files(mod.rs:2246-2250,靠 UTF-8 读取失败淘汰非文本);Go OpenDrop 明确只收 md 扩展名(shell.go:156-163)。Go 更严格,归有意偏离。

## 4. 有意偏离(不算差距)

- mojian 卡片层/accent 主题系统、居中/全宽布局、右侧独立大纲面板(Rust 是左栏统一侧栏 tab)、语言选择:Go 设计决定。
- **explorer root 模式与 markers 入口在设置对话框 Files 页**(settings.go filesGroup;markers 行仅 project_root 模式显示,settings.go:253-263):Rust 在树头部 root 菜单(file_explorer.rs:660-709)含 "Edit Markers..." 直达设置。入口位置不同、均可达,不算差距。
- **搜索栏切 tab 不关闭**:Go tabSwitched 按 tab retarget(searchbar.go:99-104);Rust activate_tab 关闭搜索栏并清高亮(mod.rs:866-875)。Go 视作增强。
- 树展开状态全局持久化一份(ExpandedDirs):Rust 每 project root 一个 explorer 实例各自缓存(mod.rs explorer_views)。体验等价。
- 状态栏的 explorer/outline 开关(Rust mod.rs:2500-2540)移到 Go 标题栏按钮(titlebar.go:102-106):mojian 决定。
- 缩放语义:Go 5% 步进 50-300% + 状态栏 HUD,Rust 2px 步进 8-48 写入 config;可感知等价。
- 拖放只收 md 扩展名(Go)vs 收任何可读 UTF-8 文本(Rust):Go 更严格。
- 标题栏工具按钮比 Rust 多(open/find/files/outline/palette/settings/menu):mojian 视觉决定。
