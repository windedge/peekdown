Peekdown 主界面 mojian 风格重设计

本文件是 Go 实现的视觉规格：颜色、圆角、阴影、字号全部取自 mojian 的 theme.go 与部件层默认值，深浅两态在 :root 与 .theme-dark 各一份。阅读列宽沿用 centeredWidth = 900（mojian 没有阅读列概念，900 是 peekdown 已验证的现值）。

标题分级与字重

标题字重按规格取 h1 700 / h2 600 / h3 500；字号沿用 mygo markdown 的 em 阶梯 1.6 / 1.35 / 1.15。段落间距 0.75em、列表项 0.25em、行高 1.65（默认 1.5，阅读器放宽）。

行内元素

行内代码如 internal/shell/titlebar.go；链接如 实现对照表；行内公式占位：E = mc^2 与 a^2 + b^2 = c^2，后续接 KaTeX 渲染。

代码块

圆角 12（Radius+2）、底色 Text alpha 4%、头部 34px 放语言标签与 Copy 按钮：

go 
// renderDoc 逐块渲染；表格与代码块让出滚动条内缩
func renderDoc(v *View, d *doc.Model) error {
    for i, b := range d.Blocks {
        if err := v.drawBlock(i, b); err != nil {
            return err
        }
    }
    return v.commit()
}

引用：3px accent 洗色左条 + TextMuted 文字（mygo QuoteBarWidth 3 / QuoteText）。
